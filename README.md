# Sky Blaster Arena — 2 Player 3D Multiplayer Prototype

A browser-playable 3D multiplayer prototype using Three.js and Socket.IO.
Players join the same room, move, aim with touch/mouse, and fire fictional energy projectiles.
This is a prototype: deploy the `server` folder to a Node.js host, then open the client URL from two devices.

## Run locally
1. Install Node.js 18+.
2. In `server/`: `npm install`
3. Run: `npm start`
4. Open `http://localhost:3000` on two devices on the same network, or use a hosted server.
5. Enter the same room code.

## Controls
- Desktop: WASD / arrow keys to move, mouse/touch to aim, FIRE to shoot.
- Mobile: on-screen movement pad + touch aim + FIRE.

Weapons are fictional sci-fi blasters. No real-world firearm instructions are included.
